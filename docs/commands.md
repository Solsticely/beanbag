# Beanbag commands

## `provision`

Set up the folder `beans/` with configuration data in the recipe books.

### Example

```sh
$ ls .
recipes.zip
$ beanbag provision recipes.zip
[2026-02-08 20:35:46,174 INFO     beanbag ] Provisioning to /home/mu/Projets/beanbag/beans...
[...]
$ ls .
recipes.zip beans
$ ls beans
datafiles logs mutexes workdirs

```

## `pack`

Create an archive. The archive can be one of four types:

1. A service archive (with `beanbag pack services [<OUTFILE>]`), which can
archive all or a selected subset of services. This package can be restored with
[`beanbag restore-backup`](#restore-backup).
2. A recipe book archive (with `beanbag pack beanbag [<OUTFILE>]`), which just
zips the recipe book, so that you can recreate the current provision on a
different machine with a single file.
3. A userdata archive (with `beanbag pack data [<OUTFILE>]`), which archives all
data 

Create a backup file from all files specified in service configurations, or from
a single service.

This process requires that any services that are being packed are stopped.
